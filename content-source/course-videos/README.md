# 内观接纳之旅视频母版

本课程共 14 个媒体文件，母版保存在项目根目录（已被 `.gitignore` 排除）：

`【禅师】强迫症的内观接纳之旅(含内观康复指导音频课程）/`

小程序不能把 638MB 视频打进代码包。正式流程：

1. 微信开发者工具 -> 云开发 -> 存储，新建 `course-videos/` 目录。
2. 按 `miniprogram/data/course-media.ts` 的 `sourceFile` 上传 14 个母版。
3. 复制每个文件的 `cloud://` fileID，填入对应 `cloudFileId`。
4. 部署云函数并重新编译。购买课程后，课程播放器会换取临时 URL 播放。

文件时长已经从母版实际媒体信息读取，不再使用估算值。
